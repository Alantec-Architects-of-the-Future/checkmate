# Security Policy

## Supported Versions

We continuously update and secure our active repositories. Please use the table below to check the support status for current versions:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our open-source projects and infrastructure very seriously. If you discover a security vulnerability within any Alantec repository, please report it responsibly.

* **Do not** open public GitHub issues for security vulnerabilities.
* Instead, please report security concerns directly via private communication channels or open a confidential advisory through the GitHub security tab if available.

We appreciate your cooperation in keeping the Alantec ecosystem secure and resilient.
